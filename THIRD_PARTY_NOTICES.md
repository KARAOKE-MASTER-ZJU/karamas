# 第三方声明

本文收录 KARAM@S 的 Windows 安装包、macOS 应用、Linux deb 安装包及 Android APK 随附的第三方组件、版权声明和许可正文。下表注明适用平台；多重许可组件注明本分发采用的许可。

Windows 的 WebView2 Runtime、macOS 系统框架，以及 Linux 的 GTK、WebKitGTK 等由系统或独立安装程序提供。下列 Rust 组件中的相关绑定代码随应用编译分发，其许可与系统库本身的许可分别适用。

版权声明、附带通知与其对应的许可正文共同构成组件的许可材料。相同正文合并收录，组件各自的署名、例外和通知分别保留。
